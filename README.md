# FocusFlow for Windows

[Download the latest version](https://github.com/bananapancakebaby-max/focusflow-updates/releases/latest)

Open the latest release and download the **FocusFlow-Setup-…-x64.exe** installer. Quit FocusFlow from its tray icon before installing. You do not need to uninstall first.

Once version 0.4.9 or newer is installed, FocusFlow checks for updates automatically, downloads new releases, and offers **Restart to update**. You can also use **Settings → Check for updates**. Install the setup version once on each PC.

This repository hosts the installers and update metadata. Your tasks, API key, tags, and sound clips are not uploaded here. Task data remains separate on each PC. New features become available after a new release is built and published.

The personal Windows builds are unsigned. Windows requires an awake PC and a running FocusFlow app for reminders. Updates do not provide task synchronization.
